🚀 Selected Projects

Silat Competition

An Android app for running a silat tournament from one dashboard. Officials set up the event, then move between match control, weigh-in, and the secretariat without leaving the same competition record.

What it covers





Event setup. Admins record the tournament name, venue, dates, number of arenas, and how many match (tanding) and artistic (seni) judges are on duty. Everyone else can open a read-only summary of those details.



Match control (tanding). Role screens for the match chief, jury hall, scoring judges, arena display, and timekeeper. Live state tracks rounds, red and blue corners, warnings, and the final result.



Weigh-in. Officials confirm each athlete’s weight against the class rules, collect coach or athlete signatures, and keep a record that can be edited or printed.



Secretariat. Athlete lists (including CSV import), draws, brackets, the schedule, arena dispatch, and match reports. Data is kept locally and can sync through Firebase Firestore and Realtime Database.

Stack for this app

Kotlin and Java, Android (min SDK 24, target SDK 35), Material Components, View Binding, and Firebase. Layouts adapt for phones, tablets, and leanback displays.

Run it





Open the project in Android Studio (AGP 8.7, Gradle 8.9, JDK 17).



Add a Firebase Android config (google-services.json) in the app module if you want cloud sync. The app still stores secretariat data on the device without it.



Build and install the app module on a device or emulator.
